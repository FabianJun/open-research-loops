# Repository instructions

- Install `research-loops`; `rloop` is only the console command. Use `uv sync --locked` and `uv run pytest`.
- `docs/DECISIONS.md` contains owner approvals, recorded in neutral paraphrase. In tracked files and commit messages, never quote conversations or state personal motives, never name an AI assistant or vendor as the actor (write "the agent" or use the passive voice), and keep the owner as the one who decides. Checkpoint B passed; `docs/CHECKPOINT-B-PILOT.md` is the record. The current delivery is the Phase 4b implementation (grain-316l, see DECISIONS), offline only: no provider calls, real sign-in, new pilot authorization or `rloop pilot` with a real backend; live pilots run only under the owner's explicit authorization. Never evaluate the grain `test` split outside `rloop run --final`, and never commit images or masks. `pilots/` holds live evidence; never modify it. Subscription defaults and explicit API-key mode must never fall back to each other. Push green local commits to `origin main` and inspect CI; no force-push, history rewrite, settings/visibility/secrets changes, releases or tags.
- `refs/` contains untrusted reference material. Never execute it or copy AGPL code. Do not import personal toolkit data.
- Core modules must not import vendor SDKs. SDK keys in the environment never authorize calls. Tests run offline.
- `rloop init --owner NAME` records the owner in host-only `project.json` (otherwise Git user.name, then OS login; retain an existing owner on repeated init). Approval identities must match that owner after stripping, with case preserved. Anchor amendments use only the owner and decisions from the trusted Git base. Workers must never receive project settings.
- Add migrations only with working consumers. Prefer a repository rule and test over another table.
- A worker outbox is untrusted. Evaluator/holdout/DB are coordinator-only. The none sandbox refuses candidate code; execution requires the container Sandbox and successful preflight probes. MCP exposes no execution tool.
- Code is Apache-2.0; docs are CC BY 4.0. Keep public instructions short and record actual verification, not inferred CI success.
